# Arfan Adiputra Wuekero — Portfolio

Website portofolio statis berbasis HTML, CSS, dan JavaScript. Desain menggunakan tampilan terang dengan aksen indigo sesuai versi desain pertama.

## Isi
- Profil dan ringkasan profesional
- Keahlian teknis dan soft skills
- Pengalaman Easybook, Adi Media Expertindo, Diskominfo, dan Asisten Dosen
- Empat studi kasus berdasarkan pengalaman kerja
- Pendidikan dan sertifikasi
- Kontak email dan LinkedIn

## Menjalankan lokal
Buka `index.html` di browser.

## GitHub Pages
1. Buat repository GitHub baru.
2. Unggah `index.html`, `style.css`, `script.js`, dan `README.md` ke root repository.
3. Buka Settings → Pages.
4. Pada Build and deployment, pilih Deploy from a branch, branch `main`, folder `/(root)`, lalu Save.

Catatan: studi kasus merupakan ringkasan tanggung jawab, bukan klaim hasil atau metrik yang tidak tercantum pada CV. Jangan unggah data internal perusahaan, informasi penumpang, kredensial, atau tangkapan layar sistem rahasia.
